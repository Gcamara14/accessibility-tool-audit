# Accordion

## MUST
- Accordion headers are keyboard-operable controls.
- Expanded/collapsed state is programmatically exposed.
- Header-control and panel relationships are linked.

## MUST NOT
- Do not use plain text headings as toggle controls.
- Do not hide expanded state from assistive technologies.

## SHOULD (V1.1 candidates)
- Support consistent multi-open vs single-open behavior docs.

## Citations
- WCAG 2.1 SC 2.1.1, 1.3.1, 4.1.2
