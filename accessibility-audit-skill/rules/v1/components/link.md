# Link

## MUST
- Use `<a href>` for navigation.
- Link text is specific and meaningful in context.
- New-tab behavior is communicated when applicable.

## MUST NOT
- Do not use button semantics for plain navigation links.
- Do not use ambiguous text like "click here" without context.

## SHOULD (V1.1 candidates)
- Standardize external link icon and announcement pattern.

- WCAG 2.1 SC 2.4.4, 2.1.1, 4.1.2
