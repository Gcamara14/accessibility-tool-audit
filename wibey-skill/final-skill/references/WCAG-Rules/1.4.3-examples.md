## Example: Small text fails 4.5:1 contrast ratio

**What failed**: Text contrast must be at least 4.5:1 for standard size text to be readable by users with low vision.

**Bad Code**:
```html
<p class="low-contrast-small-aa">This small text does not have enough contrast</p>
```

**How it was fixed**: Applied the correct semantic fix.

**Corrected Code**:
```html
<p class="low-contrast-small-aa" style="color: #595959;">This small text does not have enough contrast</p>
```

## iOS Examples

### iOS Example 1 — Placeholder Text Contrast (GPUGC-23160)

**Feature:** Recognized Reviewer Sampling Browse search field
**Ticket:** GPUGC-23160 / PR #139729

**What failed:** `UITextField.placeholder` rendered with default `UIColor.placeholderText` (~#8A8A8E on white) — contrast ratio ~3.5:1, below WCAG 4.5:1 threshold.

**Bad Code:**
```swift
browseSearchField.placeholder = "Search by product name"
// Default UIColor.placeholderText ≈ #8A8A8E — contrast 3.5:1 on white ❌
```

**Fix:** Replace `.placeholder` with `.attributedPlaceholder` using `WCPColor.gray6` (#595959, 7.0:1 on white):
```swift
browseSearchField.attributedPlaceholder = NSAttributedString(
    string: NSLocalizedString("Search by product name", comment: ""),
    attributes: [.foregroundColor: WCPColor.gray6]
)
```

**Template:** `WA11Y-IOS-1.4.3-001` — Var 1
