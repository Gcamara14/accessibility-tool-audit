## Example: Links blank link text

**What failed**: Link purpose must be clear from context.

**Bad Code**:
```html
    <a href="http://www.google.com"></a>
```

**How it was fixed**: Applied semantic HTML rule.

**Corrected Code**:
```html
    <a href="http://www.google.com">Descriptive Link Text</a>
```

## Example: Links non specific link text

**What failed**: Link purpose must be clear from context.

**Bad Code**:
```html

```

**How it was fixed**: Applied semantic HTML rule.
