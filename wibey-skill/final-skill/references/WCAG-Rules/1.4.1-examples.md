# 1.4.1 Use of Color - Pass/Fail Examples

## Example 1: Error state only indicated by red text

**What failed**: Semantic meaning was lost or inaccessible.

**Bad Code**:
```html
<span style="color:red">Invalid</span>
```

**How it was fixed**: Applied proper accessibility attributes/elements.

**Corrected Code**:
```html
<span style="color:red">Error: Invalid</span>
```

## Example 2: List items use color-coded CSS classes (`poisonous` / `safe`) to convey state

**What failed**: A list of mushrooms relied entirely on CSS color classes to tell the user which mushrooms were safe to eat and which were poisonous. Screen reader users and colorblind users wouldn't know the difference.

**Bad Code**:
```html
<p>The green mushrooms listed here are OK to eat. The red mushrooms will kill you.</p>
<ul>
  <li class="poisonous">Amanita</li>
  <li class="safe">Chanterelle</li>
</ul>
```

**How it was fixed**: Added semantic text to the list items (using a `visually-hidden` class if visual design requires it, or just plain text) so the state is conveyed explicitly in text, not just color.

**Corrected Code**:
```html
<p>The green mushrooms listed here are OK to eat. The red mushrooms will kill you.</p>
<ul>
  <li class="poisonous">Amanita <span class="visually-hidden"> - Poisonous</span></li>
  <li class="safe">Chanterelle <span class="visually-hidden"> - Safe</span></li>
</ul>
```
