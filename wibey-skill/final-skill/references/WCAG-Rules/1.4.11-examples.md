# 1.4.11 Non-text Contrast - Pass/Fail Examples

## iOS Examples

### iOS Example 1 — Grey Spinner on Background Image (CEPG-352365)

**Feature:** W+ BEN Fuel loading state
**Ticket:** CEPG-352365 / PR #147441

**What failed:** `UIActivityIndicatorView(style: .medium)` renders in system gray (`#8A8A8E`) over a hero image background. Contrast ratio against mid-tone image regions falls below 3:1.

**Bad Code:**
```swift
let loadingIndicator = UIActivityIndicatorView(style: .medium)
// UIColor.systemGray (#8A8A8E) over hero image — local contrast < 3:1 ❌
```

**Fix:** Use white spinner with semi-transparent backing scrim to guarantee ≥ 4.6:1 regardless of image content:
```swift
loadingIndicator.color = .white
loadingContainerView.backgroundColor = UIColor.black.withAlphaComponent(0.5)
// White on 50% black overlay over any background ≥ 4.6:1 ✅
```

**Template:** `WA11Y-IOS-1.4.11-001` — Var 1

### iOS Example 2 — White Spinner on White Background (CEPG-344504)

**Feature:** PHTS Purchase Plan loading overlay
**Ticket:** CEPG-344504 / PR #142246

**What failed:** Custom `CAShapeLayer` spinner using `strokeColor = UIColor.white.cgColor` on a white modal background — contrast ratio 1:1 (invisible).

**Bad Code:**
```swift
let trackLayer = CAShapeLayer()
trackLayer.strokeColor = UIColor.white.cgColor  // 1:1 on white — invisible ❌
```

**Fix:** Use `WCPColor.blue1` (Walmart blue, ~4.6:1 on white) or `WCPColor.gray6` (#595959, 7.0:1 on white):
```swift
trackLayer.strokeColor = WCPColor.blue1.cgColor  // ✅ ≥ 3:1 threshold met
```

**Template:** `WA11Y-IOS-1.4.11-001` — Var 2
