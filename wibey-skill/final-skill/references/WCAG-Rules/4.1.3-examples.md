# 4.1.3 Status Messages - Pass/Fail Examples

## iOS Examples

### Example: Filter result count not announced to VoiceOver (CEPG-332823)

**What failed:** LocalFinds feature — after selecting a subfilter, the result count label updated ("12 local shops near you") but VoiceOver made no announcement. Users had to manually navigate to the label to hear the change. iOS VoiceOver does not auto-announce `UILabel` text changes — `UIAccessibility.post` must be called explicitly.
**Template:** [`WA11Y-IOS-4.1.3-001`](../catalyst-templates/ios/WA11Y-IOS-4.1.3-001.md)

**Bad Code:**
```swift
private func updateResultsCount(_ count: Int) {
    resultsCountLabel.text = "\(count) local shops near you"
    // No UIAccessibility.post — VoiceOver is silent
}
```

**How it was fixed:** Posted `.announcement` after a 0.1 s delay; debounced rapid filter toggles with `DispatchWorkItem`.

**Corrected Code:**
```swift
private func updateResultsCount(_ count: Int) {
    let message = NSLocalizedString("\(count) local shops near you", comment: "")
    resultsCountLabel.text = message
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) {
        UIAccessibility.post(notification: .announcement, argument: message)
    }
}
```

### Example: Snackbar multi-line message truncated in VoiceOver announcement (GPUGC-21403)

**What failed:** After submitting a rating, `WCPSnackbar` appeared with title + subtitle. VoiceOver announced only the title. Root causes: (1) `.announcement` posted with `toast.titleText` only, (2) fired before toast rendered, (3) `accessibilityViewIsModal = true` trapped VoiceOver.
**Template:** [`WA11Y-IOS-4.1.3-001`](../catalyst-templates/ios/WA11Y-IOS-4.1.3-001.md)

**Bad Code:**
```swift
toast.accessibilityViewIsModal = true
UIAccessibility.post(notification: .announcement, argument: toast.titleText)
```

**How it was fixed:** Combined title + subtitle, added 0.5 s delay, set `accessibilityViewIsModal = false`.

**Corrected Code:**
```swift
toast.accessibilityViewIsModal = false
let message = "\(toast.titleText). \(toast.subtitleText)"
DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) {
    UIAccessibility.post(notification: .announcement, argument: message)
}
```

**Key rule:** For any multi-part iOS toast, always concatenate all visible text into the `.announcement` argument, delay the post until after render, and never set `accessibilityViewIsModal = true` on a transient overlay.
