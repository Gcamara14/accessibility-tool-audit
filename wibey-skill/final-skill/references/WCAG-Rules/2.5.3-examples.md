# 2.5.3 Label in Name - Pass/Fail Examples

## iOS Examples

### iOS Example 1 — WcpQuantityStepper Missing Quantity in Accessible Name (COMM-1813)

**Feature:** Registry "Add to registry" quantity stepper
**Ticket:** COMM-1813 / PR #154214

**What failed:** The visible composite UI showed "3  Add to registry" (quantity chip + action label), but `accessibilityLabel = "Add to registry"` — omitting the visible quantity. Voice Control users saying "tap 3 Add to registry" could not activate the button.

**Bad Code:**
```swift
addButton.accessibilityLabel = NSLocalizedString("Add to registry", comment: "")
// ❌ Visible text "3  Add to registry" not fully represented in accessible name
```

**Fix:** Include the quantity that appears visually so Voice Control matches:
```swift
func configure(with quantity: Int) {
    addButton.accessibilityLabel = NSLocalizedString(
        "\(quantity) Add to registry",  // ✅ contains all visible text
        comment: "Accessible name: quantity + action"
    )
}
```
