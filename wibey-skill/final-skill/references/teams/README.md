# 🏢 Teams (Layer 2: The Context)

This directory contains implementation context files named by **Team Ownership** (e.g., `web-homepage-team.md`, `ios-team.md`).

When the AI agent encounters a Jira ticket with a specific Team label, it uses these files to drastically reduce its code search space and apply the right tech stack conventions.

**What goes in here:**
- Repo paths and directory structures.
- Component ownership.
- Primary tech stack (React, Swift, Kotlin, etc.).
- Rendering models (SSR, CSR).
- Typical accessibility pitfalls and legacy constraints.
