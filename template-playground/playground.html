AI Template Generation Workflow

Use our custom GPT to generate correctly formatted JSON templates for the playground.

  1. Click the "Create Template with AI" button.

    This opens the Accessibility Bug Template Creator GPT in a new tab.

  2. Describe the bug you want a template for.

    Example: "Create me a bug for when a button is pressed on web and it gets removed from the DOM and focus is reset"

  3. Copy the JSON output.

    The GPT will generate a JSON object. Copy this code block.

  4. Paste into the Playground.

    Return to this tab, paste the JSON into the input box, and click "Load Templates".
