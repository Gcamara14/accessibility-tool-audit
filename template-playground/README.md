# Catalyst Template Playground

This folder contains a standalone HTML page for viewing and testing Catalyst bug templates.

## Usage

1. Open `playground.html` in your web browser.
2. Paste your template JSON (single object or array) into the text area.
3. Click "Load Templates".

## Folder Structure

- `playground.html`: The main entry point.
- `playground.css`: Custom styles.
- `playground.js`: Application logic.
- `assets/libs/`: Dependencies (Bootstrap, jQuery, Prism, etc.).

## Note on Icons

The Font Awesome icons are included in `assets/libs/bootstrap/webfonts/`.
These files were downloaded from the Font Awesome CDN to ensure the playground is fully offline-capable.
